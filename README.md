# おとめ座のちいさな花壇

～小さなやさしさが、花を咲かせる～

**[ゲームで遊ぶ](https://hoshi-ai-sanae.github.io/mii-vergo/)**

乙女座のちびキャラと一緒に、種から花を育てる6日間のゲームです。
マーガレット・カモミール・すずらんから種を選び、水分・栄養・元気を見ながらお世話します。
1日にひとつのお世話を選び、次の日へ進みます。実際の日付を待つ必要はありません。

## 遊び方

- お水・肥料・日なた・様子を見る、から1日1回選びます。
- 水分25〜80、栄養25〜85を目安に、必要なお世話を考えてみてください。
- 水や肥料のあげすぎ、乾燥が続くと元気が減ります。
- しおれても元気が残っていれば、適切なお世話で回復できます。
- 6日目に「元気いっぱいに開花」「小さくかわいく開花」に分岐。元気が0になると途中でも枯れます。
- お世話の手帳を振り返り、もう一度遊べます。

ゆっくり植物の様子を見ながら、約3〜5分。強制的な待ち時間はありません。

## 保存・音

記録は同じ端末・ブラウザのlocalStorageに自動保存します。ページを再読み込みしたら「つづきから育てる」で再開できます。ブラウザのデータを削除すると記録は消えます。保存できない環境では、そのことを画面に表示します。

音は起動時OFF。右上のボタンで切り替えられます。音がなくても遊べます。

登録、個人情報の入力、外部API、サーバー処理、外部ライブラリは不要です。ゲームの記録を外部に送信しません。アトリエに戻るリンクだけが外部サイトへ移動します。

## ファイル

| ファイル | 役割 |
| --- | --- |
| index.html | ページ構成 |
| style.css | PC・スマートフォン表示とアニメーション |
| engine.js | 画面から独立した育成ロジック |
| app.js | 画面、操作、保存、音 |
| art.js | 花・植物の成長段階・花壇のSVGイラスト |
| assets/ | 元画像を保った乙女座キャラクターとアイコン |
| engine.test.cjs | 育成ロジックの動作テスト |
| atelier-card.html | Lumiereへ追加するためのカード例 |

## テスト

Node.jsがあれば、追加インストールなしで実行できます。

```sh
node --test engine.test.cjs
```

22テストで、3種類×各4,096通り＝12,288通りの選択を検証します。開花、枯れ、しおれからの回復、1日1回の操作、保存データの復元、数値が0〜100に収まることを確認します。

## Lumiereへの追加

既存の「星よみアプリ・ゲーム広場」のカードと同じ構成を持つ `atelier-card.html` を用意しています。リンク先はこのゲームの公開URLです。既存カードの末尾へ追加してください。Reactで使う場合は `class` を `className` に変更し、データ配列からカードを描画している場合はその配列に1件追加します。

ゲームの公開URL： https://hoshi-ai-sanae.github.io/mii-vergo/

アトリエ本体のページは、このリポジトリから変更しません。

## 公開

GitHub Pagesのmainブランチ・ルートフォルダで公開できます。ファイルは相対パスを使い、リポジトリ配下のURLでも動作します。`.nojekyll` によりファイルをそのまま配信します。

キャラクターは提供画像のデータを変更せず使用しています。植物と花壇は本作用のSVGです。端末の「動きを減らす」設定、キーボード操作、ゲージの読み上げに対応しています。
